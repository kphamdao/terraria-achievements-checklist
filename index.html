🔄 Sync from Steam

This tool is a static page with no server of its own, and Steam's API doesn't allow websites to read your data directly (CORS). So instead: you open your own achievement data straight from Steam in a new tab, then paste it back here. Your API key and ID are only ever stored in this browser — nothing is sent to us.

  1. Get a free Steam Web API key at steamcommunity.com/dev/apikey.
  2. Find your SteamID64 (a 17-digit number) on your Steam account page.
