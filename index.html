🔄 Sync from Steam

This tool is a static page with no server of its own, and Steam doesn't allow websites to read your data directly (CORS). No API key needed either way — your SteamID is only ever stored in this browser, nothing is sent to us.

Step 1 — Get your data from Steam

Make sure Game details is set to Public under your Steam privacy settings.

Tip: open steamcommunity.com/my (redirects to your own profile) and copy whatever URL you land on.

A new tab opens with raw XML text. Select all (Ctrl/Cmd+A) and copy it (Ctrl/Cmd+C).
